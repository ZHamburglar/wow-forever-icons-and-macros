## Notes

- Icons are 56x56 JPG (the standard WoW icon render size), named exactly as in the game files (`inv_sword_36.jpg` → icon name `inv_sword_36`).
- The icon name is what you use in-game / in addons: e.g. `SetTexture("Interface\\Icons\\inv_sword_36")`.
- Categorization is derived from the game's naming conventions, so a few icons sit in "General/Other" — search `index.html` if you can't find one.
- `manifest.csv` lists every icon with its category and file size.
